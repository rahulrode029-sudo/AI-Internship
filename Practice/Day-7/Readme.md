# House Price Prediction using Machine Learning

## Project Overview

This project focuses on predicting house prices using Machine Learning techniques. 
The goal is to build a regression model that can estimate house prices based on different features such as area, number of bedrooms, bathrooms, location, and other property-related attributes.

Two machine learning algorithms were implemented and compared:

- Linear Regression
- Random Forest Regressor

The complete ML pipeline includes data preprocessing, feature selection, model training, prediction, and performance evaluation.

---

## Objectives

- Understand the machine learning regression workflow
- Perform data preprocessing and cleaning
- Split data into training and testing datasets
- Train regression models for price prediction
- Evaluate model performance using regression metrics
- Save the trained model for future predictions
