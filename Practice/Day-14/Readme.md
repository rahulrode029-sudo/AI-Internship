#  Day 14 - LLM Basics & Prompt Engineering

##  Overview

This project focuses on understanding the fundamentals of Large Language Models (LLMs) and Prompt Engineering. The objective is to learn how to create effective prompts that generate accurate, relevant, and high-quality responses from AI models. The project also demonstrates prompt comparison, text summarization, information extraction, content generation, and prompt improvement techniques.

---

## Learning Objectives

- Understand Large Language Models (LLMs)
- Learn Prompt Engineering concepts
- Understand Tokens
- Learn Temperature and its effect on AI responses
- Explore different Prompt Types
- Learn about API Keys and their purpose

---

## Tasks Completed

- Compared different prompts for the same task
- Performed Text Summarization
- Performed Information Extraction
- Generated AI content using prompts
- Improved a basic prompt through three iterations
- Compared outputs and analyzed improvements
- Completed the Mini Practical prompts
